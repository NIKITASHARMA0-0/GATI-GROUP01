🛰️ Orbital satellite Visualizer 🛰️

This project visualizes the orbits of 10 satellites using their TLE data imported from the Celestrak website, then uses skyfield to calculate the ECI coordinates and lat/long/alt of all the satellites. Then it uses Plotly to animate the satellites orbiting in their orbits around the globe. 

# Features

 Load the 30-day TLE data from the Celestrak website. 
 Converts the TLE data to ECI coordinates and lat/long/alt using the skyfield module.
 Animate a 3D interactive module of the satellite's orbits using Plotly.
 Shows multiple satellites simultaneously.
 Interactive Streamlit web app for real-time exploration.
