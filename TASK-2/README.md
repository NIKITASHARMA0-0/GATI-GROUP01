This project is an interactive satellite orbit visualizer built with Streamlit, Plotly, and Skyfield.
It uses embedded Two-Line Element (TLE) data of 10 satellites and generates their 3D orbital trajectories around Earth over the past 30 days.
✨ Features

📡 Preloaded TLE Data – No API fetching required.

🌍 3D Globe with Orbits – Interactive Plotly 3D visualization of Earth and satellite paths.

🕒 30-Day Orbit History – Simulated positions computed using Skyfield.

⚡ Fast & Self-contained – Runs offline with cached TLE data.

🌐 Deployable on Streamlit Cloud – Share your app with anyone.

📖 Background

TLE Data (Two-Line Elements) describes satellite orbits.

Skyfield propagates TLEs to calculate satellite positions.

Generative AI is used here for creating dynamic, interactive visualizations that let users explore orbital mechanics intuitively.
